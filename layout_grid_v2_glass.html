J Подключение к Jira
Токен создаётся на id.atlassian.com → Security → API tokens. Данные сохраняются только локально в этом браузере. Jira Cloud блокирует прямые запросы из браузера (CORS) — укажи адрес прокси, иначе запрос не пройдёт. Свой бесплатный прокси можно развернуть за 2 минуты: инструкция на GitHub.
C Подключение к Confluence
Email и API-токен берутся из того же Atlassian-аккаунта, что и для Jira (создать токен: id.atlassian.com). Space ID (числовой) можно найти через GET /wiki/api/v2/spaces?keys=КЛЮЧ или в URL пространства. Токен хранится только локально в этом браузере (localStorage) и никуда не отправляется, кроме самого Confluence.
Confluence Cloud блокирует прямые запросы из браузера (CORS), поэтому нужен адрес прокси — без него запрос не пройдёт. Подходит тот же прокси, что и для Jira (он работает с любыми адресами вида *.atlassian.net, включая Confluence). Разверни свой бесплатный прокси за 2 минуты: инструкция на GitHub.
